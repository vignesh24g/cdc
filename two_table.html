What happens to the joined target?

Main SCD Type 2 target

One joined history table keeps expired versions and the current active version.

A Customer change can affect every credit-interest record belonging to that customer. A Credit Interest change affects only its matching account. When both change on different dates, the target receives separate SCD2 versions at each effective date.

How the capture works

Follow the affected key from source CDC to the main SCD2 target.

Customer change

C001 phone/email changes. Both A001 and A002 belong to C001, so both joined target rows receive new SCD2 versions.

Interest change

A001 or A002 interest changes. Only that account's joined target row receives a new version.

Both, same function

Choosing "Change in Both" always calls one function. It compares the two dates you picked: equal dates → one atomic boundary; different dates → two chronological boundaries.
